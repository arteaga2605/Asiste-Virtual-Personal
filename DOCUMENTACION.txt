                    Documentación actualizada – Mayo 2025

1. DESCRIPCIÓN GENERAL
   Asistente virtual de escritorio que funciona completamente offline (salvo la
   conexión a las APIs públicas de Binance y ESPN). Usa Ollama como motor de
   lenguaje natural y ofrece áreas de especialización: trading/análisis de
   mercado (criptomonedas), pronóstico deportivo, gestión empresarial y
   programación en Python. La interfaz gráfica es un avatar animado (Toallin de
   South Park) con burbuja de chat, campo de entrada de texto, indicadores
   visuales, menú contextual y notificaciones toast.

3. REQUISITOS
   - Python 3.10 o superior.
   - Ollama instalado y corriendo (https://ollama.com).
   - Modelos descargados (llama3.1, deepseek-r1, qwen3, etc.).
   - Paquetes Python listados en requirements.txt.
   - (Opcional) Cuenta de Trello y credenciales para la integración.

4. INSTALACIÓN Y PUESTA EN MARCHA
   1. Clona o copia los archivos a una carpeta.
   2. Crea un entorno virtual:
        python -m venv venv
   3. Actívalo:
        Windows: venv\Scripts\activate
        Linux/Mac: source venv/bin/activate
   4. Instala dependencias:
        pip install -r requirements.txt
   5. Configura las variables de entorno:
        - Copia .env.example a .env
        - Edita .env con tus credenciales de Trello (si las usas) y ajusta
          cualquier otra variable según prefieras.
   6. Asegúrate de que Ollama está corriendo y has descargado los modelos:
        ollama pull llama3.1:latest
        ollama pull deepseek-r1:8b
        ollama pull qwen3:8b
   7. (Opcional) Coloca archivos CSV históricos en la carpeta data/.
   8. (Opcional) Coloca una imagen PNG con transparencia en assets/avatar.png.
   9. Ejecuta el servidor:
        python main.py
   10. El avatar aparecerá en el escritorio; escribe preguntas en su campo de
       texto y pulsa Enter.

5. MODELOS DE IA UTILIZADOS
   - Chat general y conversación: llama3.1:latest (8B parámetros, ~5 GB)
   - Trading / criptomonedas: deepseek-r1:8b (razonamiento financiero)
   - Deportes: qwen3:8b (razonamiento multilingüe)
   - Código Python: codellama:latest
   - Respaldo rápido: phi3:mini

6. ARQUITECTURA Y FLUJO DE DATOS
   - El usuario escribe en el avatar (PyQt5). El avatar envía la pregunta a
     través de un socket TCP al servidor (main.py) usando un protocolo de
     longitud prefijada (4 bytes big-endian + mensaje).
   - El servidor recibe la pregunta y, dependiendo del prefijo (__NEWS__,
     __SPORTS__, __CRYPTO__, __REPORT__, __HISTORY__, etc.), ejecuta flujos
     especializados o llama al agente normal (agent.py).
   - El agente normal (para consultas generales) utiliza tool calling con
     Ollama (modelo llama3.1) y puede invocar herramientas de trading,
     gestión, Trello o ejecución de código.
   - Las consultas especiales (noticias, deportes, cripto) usan prompts y
     modelos dedicados (deepseek‑r1 para trading, qwen3 para deportes).
   - La respuesta se envía de vuelta al avatar y se muestra en la burbuja de
     chat.
   - Todos los mensajes se guardan en una base de datos SQLite (tabla
     conversation_history), lo que permite memoria persistente.
   - El avatar posee animaciones: movimiento aleatorio (pausable al escribir),
     parpadeo, bombilla sobre la cabeza al pensar, cigarro y humo durante el
     procesamiento, y colores/expresiones de celebración por aciertos/fallos.
   - Un hilo de monitorización revisa el mercado de Binance y envía alertas
     toast al avatar si se detectan condiciones de interés.
   - Un hilo de evaluación automática revisa las predicciones de criptomonedas
     cada 2 horas y actualiza las tarjetas de Trello.

7. COMPONENTES PRINCIPALES
   - config.py:
     Contiene rutas, puerto de comunicación, modelos de Ollama, intervalo de
     refresco deportivo (45 min), límite de historial y variables de entorno.
   - agent.py:
     Define las herramientas disponibles (según el estándar de OpenAI
     functions) y el system prompt. Incluye herramientas de Trello.
   - tools/trading.py:
     Funciones para cargar CSV históricos, calcular indicadores (RSI, SMA, EMA,
     MACD), mantener precios en vivo vía WebSocket de Binance, obtener las
     monedas seleccionadas y calcular RSI en tres marcos temporales.
   - tools/business.py:
     Gestión de base de datos SQLite con tablas para notas, tareas, contactos
     y metas. Incluye seguimiento de objetivos y generación de informes.
   - tools/code_executor.py:
     Ejecuta código Python arbitrario en un subproceso aislado con timeout.
   - tools/memory.py:
     Gestiona la tabla conversation_history y permite cargar el historial.
   - tools/sports.py:
     Consulta la API pública de ESPN para obtener partidos del día en 16 ligas.
     Prioriza los de hoy y enriquece con estadísticas avanzadas.
   - tools/predictions.py:
     Almacena predicciones deportivas y de criptomonedas. Incluye filtro de
     confianza mínima (50%) y gestión de tarjetas Trello.
   - tools/alerts.py:
     Monitoriza las criptomonedas seleccionadas y tareas próximas. Genera
     alertas toast y recordatorios.
   - tools/trello.py:
     Funciones para listar tableros, listas, tarjetas, crear tarjetas, moverlas
     y añadir comentarios mediante py-trello.
   - main.py (servidor):
     Inicia el stream de Binance, el monitor de alertas, el refresco de datos
     deportivos, la evaluación automática de cripto cada 2 horas y el servidor
     TCP. Maneja los prefijos especiales:
       __NEWS__   → Joyas ocultas cripto (deepseek‑r1)
       __CRYPTO__ → Análisis individual o de todas las criptos
       __SPORTS__ → Predicciones deportivas (qwen3, con confianza)
       __REPORT__ → Reporte de aciertos/fallos y celebración
       __HISTORY__→ Historial de conversación
       __INCOME_IDEAS__ → Ideas de ingresos personalizadas
   - avatar.py (cliente gráfico):
     Ventana transparente siempre visible. Contiene:
       - Avatar de Toallin con animaciones (cigarro, humo, colores).
       - Burbuja de respuesta (QTextEdit con scroll).
       - Campo de entrada de texto.
       - Bombilla de "pensando".
       - Movimiento autónomo aleatorio (pausable al escribir).
       - Menú contextual: (No) caminar, submenús de Criptomonedas, Deporte,
         Trello, Reporte, Ideas de ingresos, Metas, Informe Semanal,
         Historial, Ocultar, Expandir/Esconder burbuja.
       - Icono en la bandeja del sistema.
       - Notificaciones toast para alertas y celebraciones.
       - Celebración visual (colores verde/rojo/naranja) al acertar/fallar.

8. FUNCIONAMIENTO DE LAS OPCIONES DEL MENÚ CONTEXTUAL
   - 🛑 No caminar / 🚶 Caminar: Pausa o reanuda el movimiento del avatar.
   - ₿ Criptomonedas: Submenú con análisis individual de cada moneda y
     "Todas las criptos". Crea tarjeta en Trello automáticamente.
   - 📰 Noticias del día: Busca 3 joyas ocultas entre las criptos configuradas.
   - 🏈 Deporte: Submenú con filtros por liga. Predice favoritos, marcador y
     confianza. Guarda las predicciones para el reporte.
   - 📋 Trello: Submenú para listar tableros, listas, tarjetas y crear tarjetas.
   - 📊 Reporte: Muestra aciertos/fallos de deportes y criptomonedas. Evalúa
     predicciones pendientes y actualiza Trello.
   - 💡 Ideas de ingresos: Analiza el historial de uso y sugiere formas de
     ganar dinero extra.
   - 🎯 Metas: Lista las metas activas.
   - 📄 Informe Semanal: Tareas completadas, notas nuevas, metas.
   - 📜 Historial: Últimas 100 interacciones.
   - 👻 Ocultar avatar: Minimiza a la bandeja del sistema.
   - ⬆️ Expandir burbuja: Aumenta la altura de la ventana.
   - ❌ Esconder burbuja: Oculta el área de respuesta.

9. ALERTAS AUTOMÁTICAS Y CELEBRACIONES
   - Monitor de criptomonedas cada 10 min: RSI 1 semana y 1 mes (>70 o <30),
     precio tocando SMA 9 en 4H, 1D, 1 semana y 1 mes.
   - Recordatorios de tareas próximas (24h).
   - Evaluación automática de predicciones cripto cada 2 horas.
   - Al acertar o fallar predicciones, el avatar cambia de color durante
     10 segundos (verde=acierto, rojo=fallo, naranja=mixto) y muestra
     notificaciones toast.

10. INTEGRACIÓN CON TRELLO
    - Requiere configurar TRELLO_API_KEY y TRELLO_TOKEN en el archivo .env.
    - Al hacer un análisis de criptomonedas, se crea automáticamente una
      tarjeta en la lista "Pendientes" del tablero "Crypto Predicciones".
    - Al evaluar la predicción (≥24h), la tarjeta se mueve a "Ganancia" o
      "Pérdida" con un comentario del resultado.
    - También puedes gestionar Trello manualmente desde el chat o el menú.

11. PERSONALIZACIÓN
    - Cambiar el modelo: edita .env o config.py (OLLAMA_MODEL, etc.).
    - Añadir más monedas: edita SELECTED_CRYPTO en tools/trading.py.
    - Modificar las ligas deportivas: edita SPORTS_CONFIG en tools/sports.py.
    - Ajustar intervalos: CRYPTO_EVALUATION_INTERVAL, SPORTS_REFRESH_INTERVAL,
      etc. en config.py.

12. SOLUCIÓN DE PROBLEMAS COMUNES
    - Error "timed out" en el avatar: aumenta el timeout del socket en
      avatar.py (actualmente 1200 s) o usa un modelo más rápido.
    - El avatar desaparece: el icono de la bandeja permite restaurarlo (doble
      clic). Si no, revisa que PyQt5 esté bien instalado.
    - La bombilla no aparece sobre la cabeza: verifica las coordenadas en
      update_bulb_position().
    - No se muestran partidos de fútbol: comprueba que la liga está en
      SPORTS_CONFIG (sports.py) y que hay partidos programados.
    - El reporte muestra "0 aciertos, 0 fallos": espera a que los partidos
      finalicen; el sistema consulta el estado real desde ESPN.
    - Alertas no aparecen: verifica que el archivo ALERT_FILE se escribe y que
      el hilo de alertas no se ha detenido.
    - Error de Trello: comprueba que el archivo .env tiene las credenciales
      correctas y que el tablero y las listas existen.
